# Dota Mobs — мод для Minecraft 26.3 (Forge 66.0.12, Java 25)

## Что в моде

| | |
|---|---|
| **Night Stalker** | Враждебный моб, спавнится только ночью под открытым небом. Когда бьёт игрока, наступает ночь (если уже ночь, время не трогает). |
| **Monkey King** | Спавнится на кронах деревьев (леса, джунгли). Очень высоко прыгает, в том числе прыжком на цель с 4–14 блоков, бьёт в ближнем бою, не получает урона от падения. Изредка превращается в корову, свинью или овцу и выглядит как настоящее животное, пока по нему не ударят. После удара превращается обратно и нападает. |
| **Alchemist** | Спавнится в шахтах (внутри структуры mineshaft). Сам не нападает. При каждом ударе игрока роняет золотой самородок и дерётся в ответ. |
| **Crystal Maiden** | Спавнится в снежных биомах, днём и ночью. Бьёт на расстоянии (до 16 блоков): немного урона, замедление III на 5 секунд, иней на экране и ледяная клетка вокруг жертвы на 5 секунд. Лёд используется «упакованный», он не превращается в воду. |
| **Крюк Пуджа** | Предмет (вкладка «Боевые предметы»). ПКМ: бросает крюк по линии взгляда на 20 блоков (стены останавливают). Первое существо на пути притягивается к вам. Перезарядка 5 сек после попадания, 2 сек после промаха. |

Яйца призыва всех мобов лежат в креативной вкладке «Яйца призыва».

## Как получить готовый мод без установки чего-либо (через GitHub)

1. Зарегистрируйтесь на github.com (бесплатно) и создайте новый репозиторий (**New repository**).
2. В репозитории нажмите **Add file → Upload files** и перетащите **всё содержимое** распакованной папки (вместе с папкой `.github` и файлом `gradlew`). Нажмите **Commit changes**.
3. Откройте вкладку **Actions**. Сборка стартует сама и занимает несколько минут.
4. Когда рядом с запуском появится зелёная галочка, откройте его и внизу в разделе **Artifacts** скачайте `dotamobs-mod`. В архиве лежит `dotamobs-1.0.0.jar`.
5. Положите джар в папку `mods`. Нужен Forge для 26.3 (версия 66.0.12 или новее).

Если сборка закончилась красным крестиком, откройте её, найдите шаг **Build** и пришлите мне текст ошибки.

## Свои скины

Сейчас стоят однотонные заглушки. Замените PNG 64×64 (формат обычного скина игрока):

```
src/main/resources/assets/dotamobs/textures/entity/night_stalker.png
src/main/resources/assets/dotamobs/textures/entity/alchemist.png
src/main/resources/assets/dotamobs/textures/entity/monkey_king.png
src/main/resources/assets/dotamobs/textures/entity/crystal_maiden.png
```

Текстура крюка: `assets/dotamobs/textures/item/pudge_hook.png` (16×16). Мобы используют модель игрока с широкими руками.
Внешний слой скина (куртка, рукава, штаны) не отображается.

## Что можно подкрутить

- `MonkeyKing.java`: `DISGUISE_ONE_IN` (чем больше, тем реже маскировка), `new HighLeapGoal(this, 4.0, 14.0)` — дальность прыжков, `JUMP_STRENGTH` — высота обычного прыжка.
- `CrystalMaiden.java`: урон (`3.0F`), уровень замедления, интервал выстрелов (`50` тиков).
- `IceCages.java`: `LIFETIME_TICKS` — сколько держится лёд.
- `PudgeHookItem.java`: дальность, перезарядка, скорость притяжения.
- `data/dotamobs/forge/biome_modifier/*.json`: вес и биомы спавна (формат `count`, как в Minecraft 26.3). У Monkey King категория MONSTER и ограничение «не больше 2 рядом» (`MAX_NEARBY` в `MonkeyKing.java`).

## Важно

Проект собран по исходникам Forge 26.3 (ветка `26.3`, сборка 66.0.12): версии, события, регистрация, время суток
(`clockManager`) сверены с кодом Forge. Но самого Minecraft 26.3 у меня не было, поэтому
**проект ни разу не компилировался и не запускался**. Наиболее вероятные места для мелких ошибок при первой сборке:
имена ванильных классов рендерера (`CowRenderer`, `SheepRenderer`, `HumanoidMobRenderer`) и сигнатура `doHurtTarget`.
Любая такая ошибка исправляется одной строкой, пришлите текст из GitHub Actions.
